3. MOTOR DE GOVERNANÇA COMERCIAL
==================================================

Quero que o RepCo evolua para ser a fonte de verdade da governança comercial da COFICO.

A arquitetura deve separar:

CORE COFICO
→ regras corporativas permanentes.

REPRESENTADA
→ condições específicas da empresa representada.

MARCA / CATEGORIA / SKU
→ dados específicos.

TABELA COMERCIAL
→ preço, piso, unidade, vigência e histórico.

POLÍTICAS
→ crédito, prazo, mix, descontos, alçadas, degustações, devoluções, marketing etc.

GERADOR DE DOCUMENTOS
→ monta Diretrizes completas, versão de bolso, tabela ou comunicado a partir dos dados vigentes.

==================================================
4. MOTOR DE DECISÃO COMERCIAL EM TEMPO REAL
==================================================

Quero transformar as Diretrizes em controles sistêmicos.

O representante NÃO deve depender de calculadora nem de memória.

Fluxo desejado:

representante monta pedido/proposta
→ RepCo identifica cliente
→ representada
→ tabela vigente
→ SKUs
→ descontos/verbas da rede
→ piso líquido
→ mix permitido
→ margem/markup
→ crédito
→ prazo
→ alçada
→ logística
→ decisão final.

Resultado visível ao representante:

🟢 PODE FECHAR

🟡 REQUER APROVAÇÃO

🔴 NÃO PERMITIDO

O sistema deve explicar o motivo sem revelar dados confidenciais.

Exemplos de motivo:
- tabela vencida;
- preço rompe piso;
- prazo fora da política;
- crédito pendente;
- verba exige aprovação;
- mix acima da alçada;
- frete precisa de validação;
- dado obrigatório ausente.
